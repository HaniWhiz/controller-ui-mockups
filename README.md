# Cisco Controller UI Mockups

A community-driven collection of lightweight, HTML-based interfaces inspired by Cisco network controllers and management platforms.

## Overview

Exploring menus and navigating the interface of a Cisco controller can sometimes require access to the actual platform. This project aims to make that process easier by collecting standalone HTML interfaces that let network engineers, students, and enthusiasts explore controller layouts directly in a web browser.

The goal is to build a shared, community-driven library of controller interfaces that anyone can explore, use for learning, or contribute to.

## Supported Platforms

The collection can include interfaces inspired by platforms such as:

- **Cisco Catalyst Center** (formerly DNA Center)
- **Cisco Identity Services Engine (ISE)**
- Cisco SD-WAN
- Cisco Meraki Dashboard
- Cisco ACI
- Other Cisco networking and management platforms

The list is not exhaustive. Contributions for additional controllers and networking platforms are welcome.

## Why This Project?

- **Quick access:** Explore menus and interface layouts without logging into a live controller.
- **Easy to use:** Open an HTML file in your browser.
- **Lightweight:** No controller appliance or backend infrastructure is required for static interfaces.
- **Community-driven:** Anyone can contribute new interfaces or improve existing ones.
- **Useful for learning:** Become familiar with navigation, menus, and dashboard organization before working with the real platform.

## Getting Started

No installation is required for standalone HTML interfaces.

1. Browse the repository and find the controller interface you want to explore.
2. Download the relevant HTML file or clone the repository.
3. Open the HTML file in your web browser.
4. Explore the available menus and interface elements.

To clone the repository:

```bash
git clone https://github.com/HaniWHiz/controller-ui-mockups.git
cd controller-ui-mockups
```

> Note: Features that depend on a real controller, backend services, authentication, or live network data will not work unless explicitly implemented.

## Community Contributions

**Everyone is welcome to contribute!**

This repository is intended to be a shared collection of controller interfaces, and community participation is encouraged.

You can contribute by:

- Adding HTML interfaces for Cisco controllers.
- Improving existing layouts, menus, and navigation.
- Adding CSS, JavaScript, and supporting assets.
- Fixing bugs or improving usability.
- Documenting controller interfaces and their features.
- Suggesting additional platforms to include.

### How to Contribute

1. Fork this repository.
2. Create a branch for your changes.
3. Add your HTML interface and any required assets.
4. Keep files organized and include a short description of the controller and interface.
5. Test your changes in a web browser.
6. Commit and push your changes to your fork.
7. Open a pull request describing your contribution.

If you are unsure where to start, open an issue to suggest a new controller interface or discuss an improvement.

### Contribution Guidelines

- Prefer standalone HTML files when practical.
- Keep the interfaces lightweight and easy to run locally.
- Organize assets and supporting files clearly.
- Do not include credentials, secrets, private configuration, or sensitive information.
- Clearly identify mock interfaces and avoid presenting them as functional Cisco products.
- Respect applicable trademarks, copyrights, and licensing terms.
- Do not include proprietary Cisco source code or assets unless you have permission to redistribute them.
